# IMP-01 AIX Master Implementation Handover
## 09 Security Compliance Evidence Checklist

## 1. Evidence Categories

1. architecture diagrams.
2. API documentation.
3. database schema.
4. permission matrix.
5. audit event catalogue.
6. test results.
7. deployment logs.
8. security scans.
9. reconciliation reports.
10. incident drill evidence.
11. UAT sign-off.
12. management approval.

## 2. Compliance Evidence

Required:

1. licence-scope feature-lock evidence.
2. onboarding eligibility evidence.
3. KYC/KYB evidence.
4. AML/sanctions screening evidence.
5. Travel Rule evidence.
6. wallet screening evidence.
7. payout whitelist evidence.
8. client money safeguarding evidence.
9. ledger immutability evidence.
10. reconciliation evidence.
11. incident/freeze drill evidence.
12. portal display truth evidence.

## 3. Security Evidence

Required:

1. authentication/MFA tests.
2. RBAC/SoD tests.
3. audit tamper-evidence.
4. encryption evidence.
5. secret management evidence.
6. vulnerability scan.
7. dependency scan.
8. penetration test scope/result.
9. web security tests.
10. export control tests.
11. incident response test.

## 4. Go-Live Evidence

Before go-live:

1. all critical tests pass.
2. no unresolved critical/high security findings unless risk accepted.
3. no unresolved critical reconciliation breaks.
4. safeguarding dry-run clean.
5. incident freeze drill passed.
6. management approval.
7. compliance approval.
8. finance approval.
9. security approval.
10. deployment rollback plan ready.
