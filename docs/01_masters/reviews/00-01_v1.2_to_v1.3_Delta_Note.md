### Defect (minor) — duplicated FX params in §9.5

The §9.5 blocking-dependency parameter block **duplicates four FX lines**, with `fx_movement_bearer` given two different values:

```txt
fx_rate_source = to_be_defined
fx_rate_timestamp_source = server_utc
fx_rounding_policy = to_be_defined
fx_movement_bearer = client_or_void_requote_no_aix_absorption_before_SRS   # <-- variant 1
fx_rate_source = to_be_defined            # duplicate
fx_rate_timestamp_source = server_utc     # duplicate
fx_rounding_policy = to_be_defined        # duplicate
fx_movement_bearer = client_or_void_requote_no_aix_absorption             # <-- variant 2 (conflicting)
```

Copy-paste artifact. **Recommendation:** de-duplicate and keep a single `fx_movement_bearer` value. Cosmetic/consistency only — the later §27 consolidated param block is clean. Non-blocking.

**RESOLVED (2026-07-09):** the duplicated lines were removed from `01_Project_Charter_v1.3.md §9.5`; `fx_movement_bearer = client_or_void_requote_no_aix_absorption` now appears once in §9.5 and once in §27, both identical.
